📖 Как опубликовать игру на автомате
Вариант 1. Быстро — встроить код в автомат
  1. Экспортируйте игру в HTML (см. подсказки для каждой платформы).
  2. На вкладке «Добавить игру» выберите платформу и «HTML код».
  3. Вставьте код в поле и нажмите «Опубликовать». Игра сразу появится в карусели автомата.
Вариант 2. Через GitHub Pages (для больших игр и Godot)
  1. Создайте аккаунт на github.com.
  2. Новый репозиторий → загрузите index.html и все файлы игры.
  3. Settings → Pages → Source: main / /(root) → Save.
  4. Через 1–2 минуты игра доступна по ссылке
    https://ваш-логин.github.io/имя-репозитория/
  5. Вставьте эту ссылку в поле «URL игры» в панели разработчика.
Готовые сборщики:
  • Scratch → HTML: packager.turbowarp.org
  • Processing → p5.js: editor.p5js.org → Share → Embed
  • Godot → Web: Project → Export → Web → HTML5
