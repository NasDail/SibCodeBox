📖 Как опубликовать игру
Способ 1. Готовый HTML (≤ 10 МБ)
  1. Экспортируйте игру в HTML (Scratch → TurboWarp, Processing → p5.js).
  2. Перетащите .html в зону загрузки в панели разработчика.
  3. Заполните метаданные и нажмите «Опубликовать».
  4. Игра сохранится в Supabase Storage, ссылка появится в каталоге автомата.
Способ 2. Большой HTML (> 10 МБ)
  1. В настройках учителя заполните GitHub owner/repo/token.
  2. Файл автоматически загрузится через GitHub API.
  3. Ссылка будет через jsDelivr CDN — быстрая и бесплатная.
Способ 3. Готовая ссылка
  1. Залейте игру на GitHub Pages / itch.io / Vercel.
  2. Выберите «Ссылка» и вставьте URL.
Готовые сборщики:
  • Scratch → HTML: packager.turbowarp.org
  • Processing → p5.js: editor.p5js.org
  • Godot → Web: Project → Export → Web
  • Unity → WebGL: File → Build Settings → WebGL
