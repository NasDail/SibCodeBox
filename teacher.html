📖 Как опубликовать игру
HTML ≤ 10 МБ
  1. Загрузите .html → уйдёт в Supabase Storage.
  2. Ссылка появится в каталоге автомата.
ZIP любой размер
  1. Внутри архива должен быть index.html (в корне или в подпапке).
  2. Файл распакуется в браузере, все файлы уйдут в GitHub одним коммитом.
  3. Игра откроется через jsDelivr CDN с правильными MIME.
  4. Относительные пути (assets/, wasm/, pck/) работают.
Готовая ссылка
  1. Залейте на GitHub Pages / itch.io / Vercel, вставьте URL.
Сборщики:
  • Scratch: packager.turbowarp.org → HTML или ZIP
  • Processing: editor.p5js.org → HTML/ZIP
  • Godot: Export → Web → ZIP
  • Unity: Build Settings → WebGL → ZIP
